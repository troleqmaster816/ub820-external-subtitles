# GNU C Library

The prebuilt helper statically links GNU C Library 2.39, licensed under
LGPL-2.1-or-later. The license is in [glibc-LGPL-2.1.txt](glibc-LGPL-2.1.txt).

The ARM build uses Ubuntu's `libc6-armhf-cross` and `libc6-dev-armhf-cross`
packages, version `2.39-0ubuntu8cross1`, generated by
[`cross-toolchain-base` 68ubuntu5](https://launchpad.net/ubuntu/+source/cross-toolchain-base/68ubuntu5)
from [`glibc` 2.39-0ubuntu8](https://launchpad.net/ubuntu/+source/glibc/2.39-0ubuntu8).
Those source packages contain the library sources and packaging changes.

The helper sources and generated payloads are included in this repository.
Follow [the build instructions](../../CONTRIBUTING.md#building-the-helper) to
rebuild and relink the helper with a modified compatible library. The normal
helper build needs the ARM cross-development library, not just the host libc.
